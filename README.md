## Задание 1: Юнит-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы юнит-тесты для класса `Burger` с использованием **моков** (Bun, Ingredient) и **параметризации** (pytest.mark.parametrize) для расчёта цены, чека, удаления/перемещения ингредиентов.

### Структура проекта

- `praktikum` - пакет, содержащий код программы
- `tests` - пакет с тестами (например, `burger_test.py` для класса Burger).

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`  
> (при ошибке прав: `pip install --user -r requirements.txt`)

**Запуск автотестов и создание HTML-отчета о покрытии**

>  `$ pytest --cov=praktikum --cov-report=html`
